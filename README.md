# Entregável · App Calendário

Área da cliente do **Calendário de Maria 2027** (Ponto da Fé).

Aplicativo web entregue após a compra na Kiwify: calendário mensal ilustrado de 2027, páginas devocionais, guia das festas marianas, caderno de intenções e, no Plano Completo, os bônus (50 cartões de oração, Preparando 2027, versão econômica e comunidade).

Site estático publicado pelo GitHub Pages (branch `main`, pasta raiz). Cada plano fica em sua própria pasta, e o acesso é feito pelo link enviado na entrega da compra.
